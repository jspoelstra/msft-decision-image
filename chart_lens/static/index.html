READ BEFORE INTERPRETING

Curiosity, with guardrails.

An image-only claim verification experiment, not a trading system.

What is being checked?

“The target experienced a smaller maximum drawdown than the comparison over the displayed 30 sessions.” Maximum drawdown is the largest percentage decline from an earlier closing-price peak to a later trough, both inside this window. Smaller is better; equal drawdowns contradict the claim. Flat or rising paths have zero drawdown.

The two anonymous paths share a starting baseline. Measure each loss relative to its earlier peak, not as the vertical percentage-point drop on the chart. Final endpoints alone cannot answer this question. Prices are split-adjusted, not dividend-adjusted. The upper target-price panel retains historical 52-week extremes for context. No future prices are predicted.

What does Decision see?

Only the rendered chart and fixed rubric. No tickers, calendar dates, drawdown values, ground truth, news, or numerical market features accompany the image. Numerical truth is attached only after the judgment is saved.

Decision can select Supported, Contradicted, or Insufficient visual evidence. The last choice is an abstention, not a third kind of numerical truth. No written rationale is invented.

How to read the results

Accuracy, balanced accuracy, and F1 use answered claims. Answer coverage shows answered / evaluated; evaluation coverage shows evaluated / requested. Overall accuracy counts abstentions as incorrect. Probability losses and calibration include abstentions.

The confusion matrix includes abstentions. Drawdown-margin slices reveal near-ties versus obvious gaps. A positive Comparison-minus-Target margin supports the claim. Baselines use the same answered sessions; historical majority uses only earlier windows. Small samples are exploratory and overlapping windows are dependent. Visual accuracy is not forecasting ability.

Data & operating modes

Live mode uses Microsoft Foundry. Demo mode uses synthetic scores, NOT Foundry judgments. Legacy forecast and SPY-outperformance runs remain inspectable under their original labels and reports, but cannot resume as drawdown comparisons.

Yahoo Finance data via yfinance is for this local personal experiment. Confirm applicable data terms before hosted-model processing or sharing exports. No silent provider substitution.
